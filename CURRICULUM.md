# 📚 The Curriculum — Beginner → Pro in 180+ days

Four phases. Every 7th day is a **review/refactor day**. Each phase ends with a **capstone** you can show off.
Adjust freely — momentum beats perfection. Too easy? Do the bonus. Too hard? Split the day.

## 🟢 Phase 1 — Beginner (Days 1–30)

**Goal:** comfortably write small programs using only the standard library.
**Concepts:** variables, types, strings & f-strings, input/output, conditionals, loops, lists, dicts, functions, file I/O, errors, `random`/`time`/`csv`/`datetime`.

## 🟡 Phase 2 — Intermediate (Days 31–75)

**Goal:** structure real programs — OOP, packages, external libraries, persistence, tests, GUIs.
**New tools:** venv · pip · requests · BeautifulSoup · sqlite3 · Tkinter · pytest · argparse · logging

| Days | Theme | Projects |
|---|---|---|
| 31–37 | OOP | bank account class · deck of cards · library system · inheritance zoo · dunder-method vector math · `@property` bank v2 · OOP flashcards |
| 38–44 | Modules, pip, APIs | packages & imports · venv + requirements · argparse CLI tool · weather CLI (requests) · currency converter API · JSON notes app · 🔁 review |
| 45–51 | Files, scraping, SQLite | logging module · pathlib file organizer · news scraper (bs4) · scrape table → CSV · SQLite habit tracker · SQL joins report · 🔁 review |
| 52–58 | GUI (Tkinter) | GUI calculator · to-do GUI · paint canvas · quiz GUI · 🔁 review |
| 59–65 | Testing (pytest) | TDD fizzbuzz · test the bank · fixtures & parametrize · mock an API · 🔁 review |

| 73–75 | 🏁 Mid capstone | Expense Tracker v2: SQLite + GUI + reports |

## 🟠 Phase 3 — Advanced (Days 76–120)

**Goal:** production-shaped Python — async, web services, data, containers.
**New tools:** decorators · generators · context managers · typing/dataclasses · asyncio · FastAPI · SQLAlchemy · pandas · matplotlib · Docker · threading/multiprocessing

| Days | Theme | Projects |
|---|---|---|
| 76–80 | Functional core | closures · decorators (timer, retry) · generators (log stream) · itertools deep-dive · context managers |
| 81–85 | Types & data | type hints everywhere · dataclasses · pydantic models · enum & NamedTuple · config manager |
| 86–90 | Async | asyncio basics · async downloader · async scraper (aiohttp) · rate limiter · 🔁 review |
| 91–100 | Web (FastAPI) | first API · CRUD + pydantic · SQLAlchemy DB · JWT auth · middleware/errors · httpx tests · uvicorn locally · 🔁 review |
| 101–107 | Data analysis | pandas basics · clean a messy dataset · analyze your expenses · matplotlib charts · mini dashboard · 🔁 review |
| 108–112 | Design patterns | strategy · observer · factory · singleton (and when *not* to) · refactor an old project with them |
| 113–117 | Concurrency | threading downloader · multiprocessing crunch · queue-based worker · locks & race conditions |
| 118–120 | 🏁 Capstone | Personal REST API: FastAPI + DB + tests + Docker |

## 🔴 Phase 4 — Pro (Days 121–180+)

**Goal:** ship. Deploy, automate, publish, contribute — then keep learning forever.

| Days | Theme | Projects |
|---|---|---|
| 121–130 | Full-stack | FastAPI backend + frontend (HTML/JS or React) · auth · file uploads · pagination |
| 131–140 | Ship it | deploy (Render/Railway/Fly.io) · env config & secrets · logging/monitoring · CI/CD with GitHub Actions |
| 141–150 | Ecosystem | package a CLI · publish to PyPI · docs (MkDocs) · ruff/black/pre-commit · contribute a PR to open source |
| 151–160 | Performance & scale | cProfile profiling · caching · DB indexes & query tuning · load testing |
| 161–170 | ML taster | scikit-learn iris · spam classifier · regression on real data · (optional) LLM API playground |
| 171–180 | 🏁 Grand capstone | SaaS-style app: API + frontend + auth + payments (test mode) + deployment + CI |
| 181+ | Forever | daily katas (Codewars/LeetCode) · read a PEP weekly · build in public · teach what you learn |
